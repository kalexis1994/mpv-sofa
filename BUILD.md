# Build Instructions

## Prerequisites

### Required Software
- **Visual Studio 2022** (with C++ workload)
- **MSYS2** (for building mpv and its dependencies)
- **Git** (comes with MSYS2 and VS)
- **CMake** (>= 3.20, install from cmake.org or VS installer)
- **Rust** (for lossless HD FFI, install from rustup.rs)

### Install MSYS2 Packages
Open MSYS2 UCRT64 terminal and run:

```bash
pacman -Syu
pacman -S \
    mingw-w64-ucrt-x86_64-gcc \
    mingw-w64-ucrt-x86_64-cmake \
    mingw-w64-ucrt-x86_64-meson \
    mingw-w64-ucrt-x86_64-ninja \
    mingw-w64-ucrt-x86_64-pkg-config \
    mingw-w64-ucrt-x86_64-ffmpeg \
    mingw-w64-ucrt-x86_64-libass \
    mingw-w64-ucrt-x86_64-lcms2 \
    mingw-w64-ucrt-x86_64-libjpeg-turbo \
    mingw-w64-ucrt-x86_64-libplacebo \
    mingw-w64-ucrt-x86_64-shaderc \
    mingw-w64-ucrt-x86_64-vulkan-loader \
    mingw-w64-ucrt-x86_64-spirv-cross \
    mingw-w64-ucrt-x86_64-glfw \
    mingw-w64-ucrt-x86_64-glm \
    mingw-w64-ucrt-x86_64-libmysofa \
    git
```

## Build Steps

### Step 1: Clone and Setup

```bash
cd /path/to/mpv-sofa

# Clone submodules for the host app
git submodule add https://github.com/glfw/glfw external/glfw
git submodule add -b docking https://github.com/ocornut/imgui external/imgui
git submodule add https://github.com/g-truc/glm external/glm
git submodule add https://github.com/marton78/pffft external/pffft
```

### Step 2: Patch mpv

```bash
# We already cloned mpv-src. Apply our patches:

# Copy the HRTF audio filter
cp mpv-patches/af_hrtf.c mpv-src/audio/filter/af_hrtf.c

# Copy PFFFT source into mpv (for the filter's convolution)
cp external/pffft/pffft.c mpv-src/audio/filter/pffft.c
cp external/pffft/pffft.h mpv-src/audio/filter/pffft.h

# Patch user_filters.h - add extern declaration
# (manually add: extern const struct mp_user_filter_entry af_hrtf;)

# Patch user_filters.c - add to af_list[]
# (manually add: &af_hrtf, to the array)

# Patch meson.build - add libmysofa dependency and af_hrtf.c source
# (see mpv-patches/meson.build.patch for details)

# Patch meson.options - add hrtf option
# (add: option('hrtf', type: 'feature', value: 'auto', description: 'HRTF'))
```

### Step 3: Build mpv (with HRTF filter)

From MSYS2 UCRT64 terminal:

```bash
cd mpv-src

# Configure with HRTF enabled
meson setup build \
    --buildtype=release \
    -Dlibmpv=true \
    -Dhrtf=enabled

# Build
meson compile -C build

# The outputs are:
# mpv-src/build/libmpv-2.dll    (shared library)
# mpv-src/build/libmpv.dll.a    (import library for linking)
# mpv-src/build/mpv.exe         (CLI player with HRTF filter)
```

### Step 4: Build Rust FFI (optional, for full spatial)

```bash
cd rust_hrtf

# Build static library
cargo build --release

# Output: rust_hrtf/target/release/losslesshd_ffi.lib
# Header: rust_hrtf/include/losslesshd_ffi.h (auto-generated by cbindgen)
```

### Step 5: Generate GLAD (OpenGL loader)

Go to https://glad.dav1d.de/ and generate:
- Language: C/C++
- Specification: OpenGL
- API gl: Version 4.1
- Profile: Core
- Generate a loader: checked

Download and extract to `external/glad/`:
- `include/glad/glad.h`
- `include/KHR/khrplatform.h`
- `src/glad.c`

### Step 6: Build Host Application

From a Developer Command Prompt for VS 2022:

```cmd
cmake -B build -G "Visual Studio 17 2022" ^
    -DMPV_INCLUDE_DIR=mpv-src/include ^
    -DMPV_LIBRARY=mpv-src/build/libmpv.dll.a

cmake --build build --config Release
```

Or from MSYS2 (Ninja):
```bash
cmake -B build -G Ninja \
    -DCMAKE_BUILD_TYPE=Release \
    -DMPV_INCLUDE_DIR=mpv-src/include \
    -DMPV_LIBRARY=mpv-src/build/libmpv.dll.a

cmake --build build
```

### Step 7: Run

```bash
# Copy libmpv DLL next to executable
cp mpv-src/build/libmpv-2.dll build/bin/

# Run
./build/bin/mpv-sofa.exe

# Or with a file:
./build/bin/mpv-sofa.exe movie.mkv
```

## Quick Test (mpv CLI with HRTF filter only)

If you just want to test the HRTF filter without the GUI:

```bash
# After building mpv with the HRTF patch:
./mpv-src/build/mpv.exe --af=hrtf=sofa=assets/hrtf/default.sofa movie.mkv
```

This plays the movie with binaural HRTF spatialization on headphones.

## Directory Structure After Build

```
hrtf/
├── build/
│   └── bin/
│       ├── mpv-sofa.exe   (our GUI app)
│       ├── libmpv-2.dll           (mpv library)
│       └── assets/
│           └── hrtf/default.sofa  (HRTF data)
├── mpv-src/
│   └── build/
│       ├── mpv.exe                (CLI player with HRTF)
│       └── libmpv-2.dll
├── mpv-patches/                   (our mpv modifications)
├── rust_hrtf/                     (Spatial decoder FFI)
├── src/                           (host app source)
└── external/                      (dependencies)
```
